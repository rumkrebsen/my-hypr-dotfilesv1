# my-hypr-dotfilesv1
Personal Arch Hyprland configuration, tailored to my own workflow. Not intended as a plug-and-play setup.

Dependencies, packages:

kitty, waybar, wofi, hyprpaper, waypaper, matugen, cliphist, wl-clipboard, grim, slurp, playerctl, brightnessctl, thunar, hyprlauncher, zen-browser, fastfetch.

Dependencies, fonts:

Geist Mono, SpaceMono Nerd Font, Font Awesome, Roboto, Google Sans Flex.

First run. Run matugen image <wallpaper> ... once so the color files exist.
